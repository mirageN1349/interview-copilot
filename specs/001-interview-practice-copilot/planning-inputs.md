# Planning Inputs: Interview Copilot

- **PI-001 — Authentication**: использовать Better Auth для входа по magic link на email.
- **PI-002 — Transcription choices**: предусмотреть пользовательский выбор Whisper large-v3-turbo и Parakeet; на планировании проверить доступность, лицензии, задержку и границы передачи данных для каждой конфигурации.
- **PI-003 — Target platform**: первая версия — desktop-приложение для macOS из-за требований к Accessibility, screen recording, нескольким мониторам и поведению overlay.
- **PI-004 — Subscription prototype**: реальный платёжный контур не создавать; мок-действие сразу выдаёт тестовый entitlement.
- **PI-005 — Security boundary**: allowlist, run gate, аудит, kill switch и запрет реальных интервью являются обязательными, а не опциональными элементами плана.
- **PI-006 — Data boundary**: отдельно определить и проверить границы обработки для вакансий, резюме, проектных материалов, аудио, скриншотов, сообщений и AI-ответов; передача за неутверждённую границу должна блокироваться.
- **PI-007 — Retention**: содержимое встреч хранится 30 дней по умолчанию и может иметь только более короткий срок; аудит хранится 365 дней.
- **PI-008 — Stealth matrix**: минимальная матрица включает full-display, single-window и системную запись экрана, а также Dock, menu bar, app switcher и notifications; конкретные утверждённые приложения и версии ОС фиксируются в плане и тестовом контракте.
- **PI-009 — Product language**: обычный UI использует нейтральные consumer-термины и стандартные сценарии interview assistant; внутренние роли, политика запуска, аудит и тестовая терминология доступны только в ограниченной диагностике.
